TEST135 — MIDI channels per bank evidence

Correct model resource param.xml: MidiMixCtlChannelsPerBankDiscrete has eight
ordered items labelled 1 through 8. Globals.xml sets the underlying value's
default to 8; the bank index remains separate and read-only in this app.

AFCC agent SHA256:
7a6b805d11170c9f35731b40f83c48efacfd248edc95c7baf6c6e01faad13513
Registration 0x140494e7c..494e9d calls 0x1404a3f10. That helper sets parameter
0x12 and element 0, then constructs the handler at 0x1404c5200.
Its writer vtable 0x140d71f48 dispatches via 0x1404cc200 to 0x1404c4960.
At 0x1404c4c70..4c4c7d the discrete index is converted and 1.0 is added
(constant 0x140db3b44), yielding the raw 1..8 value.
Writer 0x1404c4f50 passes the value to the generic setter 0x14048faa0 at
0x1404c50db..4c50f0 using state group 3. The established AF16Rig device
setter adds 0x10 to the group: OUT 0x40/0x13, parameter18, index0, two LE bytes.
Readback uses the existing IN 0xc0/0x93 path.

The app verifies firmware/state version18 and two matching reads of the
expected previous size before sending one OUT. Confirmation uses reads only.
No-op changes send no OUT. Invalid values, stale connection generations and
external changes are rejected. Failed writes are not automatically retried.
The assignment table is refreshed after success to show device-returned bank
state; this app does not write bank index or synthesize a new bank position.
The native app also updates local controller UI state after its write; this
release refreshes its own captured view from the device instead.

Automated tests use fake USB transport and demo devices. Physical controller
bank behavior still needs verification on the actual Rig16.
